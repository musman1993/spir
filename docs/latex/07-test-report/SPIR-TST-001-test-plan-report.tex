\section{Test approach}
\subsection{Levels}
\begin{description}
  \item[Unit] The label-validation engine is pure TypeScript with no I/O; every comparison method and policy rule has
    direct tests.
  \item[API integration] The whole Hono application runs in-process against \textbf{PGlite} (Postgres compiled to
    WebAssembly) with the real migrations and the real seed CSV, an in-memory object store and real portal sessions.
    Requests go through routing, authentication, validation and SQL exactly as in production.
  \item[Golden corpus] The real Tesseract.js and ZXing output for six synthetic label photos (\fpath{seed/labels/}) is
    stored as fixtures, so OCR behaviour is regression-tested without running OCR in CI.
  \item[Private corpus] The same check for real label photos, stored only on the developer machine (git-ignored).
  \item[Browser] Headless Chrome (Playwright) walk-throughs of the user journeys, with screenshots reviewed at
    1440\,px and 390\,px wide.
  \item[QR decoding] Printed sheets rendered to PDF and decoded by two independent decoders (OpenCV, zxing-cpp)
    under simulated phone conditions (low resolution, blur, noise, tilt, dim light).
\end{description}

\subsection{Environment}
Node 24, Vitest 3, PGlite 0.4; Chrome headless; Python 3 with OpenCV and zxing-cpp for QR measurement. CI: GitHub
Actions \fpath{ci.yml} on every push and pull request (typecheck, API tests, web build).

\subsection{Entry and exit criteria}
Entry: code compiles; migrations apply to an empty database. Exit: all automated tests pass, typecheck and build pass,
no open defect of severity high, browser walk-through of changed journeys reviewed.

\section{Gaps and recommendations}
\begin{itemize}
  \item No automated browser (end-to-end) tests in CI; the walk-throughs are manual scripts. Add Playwright to CI.
  \item No security testing (dependency audit, SAST, DAST, penetration test) --- required before production.
  \item No load or performance tests; targets are not yet agreed (NFR-PERF-001).
  \item OCR accuracy measured on 6 synthetic and 3 real photos only; build a labelled set of 100+ real labels and report
    per-field precision and recall (NFR-OCR-001).
  \item No accessibility audit with assistive technology.
\end{itemize}
